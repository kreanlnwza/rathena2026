========================================================
  rAthena Discord Bot — รายการคำสั่งทั้งหมด
========================================================
[ADMIN] = ต้องการสิทธิ์ผู้ดูแลหรือยศ ADMIN_ROLE_ID

────────────────────────────────────────────────────────
  บัญชีผู้เล่น
────────────────────────────────────────────────────────
/register
    สมัครบัญชีเกมใหม่ผ่าน popup form
    ขั้นตอน: กรอกฟอร์ม → เลือกเพศ → CAPTCHA → สร้างบัญชี
    - Username : a-z A-Z 0-9 เท่านั้น ห้ามอักขระพิเศษ (6–23 ตัว)
    - Password : ต้องมีพิมพ์เล็ก + พิมพ์ใหญ่ + ตัวเลข (≥6 ตัว)
    - วันเกิด  : รูปแบบ ddmmyyyy เช่น 29061989
    - 1 Discord สมัครได้สูงสุด 3 ID
    - ผูก Discord ↔ บัญชีเกมอัตโนมัติหลังสมัครสำเร็จ

/changepassword
    เปลี่ยนรหัสผ่านบัญชีเกม
    (username, รหัสเดิม, รหัสใหม่ที่ต้องมีพิมพ์เล็ก+ใหญ่+ตัวเลข)

/unlink [username]
    ยกเลิกการผูก Discord กับบัญชีเกม
    ถ้าระบุ username จะยกเลิกเฉพาะ ID นั้น
    ถ้าไม่ระบุ จะยกเลิกทุก ID ที่ผูกไว้

/whoami
    แสดงบัญชีเกมทั้งหมดที่ผูกกับ Discord ของคุณ (สูงสุด 3/3)
    บันทึกใน MySQL ตาราง discord_links

/accountinfo <username>                          [ADMIN]
    ดูข้อมูลบัญชีโดยละเอียด
    (account_id, สถานะ, GM level, VIP, IP ล่าสุด)

────────────────────────────────────────────────────────
  ตัวละคร
────────────────────────────────────────────────────────
/charinfo <name>
    ดูข้อมูลตัวละคร
    (level, stats, zeny, map, guild, online/offline)

/online
    แสดงรายชื่อผู้เล่นที่ online อยู่ขณะนี้ (สูงสุด 25 คน)

────────────────────────────────────────────────────────
  เซิร์ฟเวอร์
────────────────────────────────────────────────────────
/serverstatus
    แสดงสถานะเซิร์ฟเวอร์แบบ realtime
    - ผู้เล่น online / บัญชีทั้งหมด / ตัวละครทั้งหมด
    - สถานะโปรเซส: 🟢/🔴 Login | Char | Map | Web | Bot
    - สีกรอบเป็นแดงเมื่อ core server ตัวใดตัวหนึ่งดับ

  [AUTO STATUS — ไม่ใช่คำสั่ง]
    บอทจะส่ง embed สถานะในห้องที่กำหนด (STATUS_CHANNEL_ID)
    และ edit message เดิมแทนการส่งใหม่ทุกครั้ง
    - ตรวจ DB ทุก STATUS_POLL_INTERVAL วินาที (ค่าเริ่มต้น 30)
    - อัปเดต Discord เฉพาะเมื่อข้อมูลเปลี่ยนแปลง
    - บังคับ refresh ทุก ~10 นาที แม้ข้อมูลไม่เปลี่ยน
    - จำ message ID ไว้ใน data/status_message.json

/totalzeny
    ยอด Zeny รวมทั้งหมดในเซิร์ฟเวอร์ + Top 10 ร่ำรวยสุด

────────────────────────────────────────────────────────
  ไอเทมและ Drop
────────────────────────────────────────────────────────
/recentdrops [limit]
    ดูการดรอปไอเทมล่าสุด (อาวุธ/เกราะ/การ์ด)

/droprate <item_name>
    ดู Drop Rate ของไอเทม ค้นจากชื่อ
    แสดง mob ที่ดรอปพร้อม rate และ rarity

  Admin — จัดการ Discord Server                  [ADMIN]
────────────────────────────────────────────────────────

    color: hex เช่น ff0000 (ค่าเริ่มต้น ffffff)

────────────────────────────────────────────────────────
  ข้อความต้อนรับ                                  [ADMIN]
────────────────────────────────────────────────────────
  [AUTO WELCOME — ไม่ใช่คำสั่ง]
    เมื่อมีสมาชิกใหม่เข้า Discord บอทจะส่ง embed ต้อนรับ
    พร้อมลิงค์โยนไปห้อง register อัตโนมัติ
    ตั้งค่าผ่าน WELCOME_CHANNEL_ID ใน .env หรือ /welcome set

/welcome set <channel> [message]
    ตั้งค่าห้องสำหรับส่งข้อความต้อนรับ
    message: ข้อความ custom (ถ้าไม่กรอกใช้ข้อความเริ่มต้น)
    ตัวแปรที่ใช้ได้ในข้อความ:
      {member}           — mention สมาชิกใหม่
      {guild}            — ชื่อเซิร์ฟเวอร์
      {register_channel} — mention ห้อง register

/welcome test
    ทดสอบส่ง embed ต้อนรับไปห้องที่ตั้งไว้ทันที

/welcome info
    ดูการตั้งค่าปัจจุบัน (ห้อง + ข้อความ)

────────────────────────────────────────────────────────
  Reaction Role                                   [ADMIN]
────────────────────────────────────────────────────────
/rr add <channel> <role> [label] [description]
    สร้างปุ่มรับยศในช่องทาง (มี CAPTCHA ยืนยัน)
    label: ข้อความบนปุ่ม (ค่าเริ่มต้น: 🎮 รับยศ)

/rr remove <message_id>
    ลบปุ่มรับยศออกจากระบบและลบข้อความนั้น

/rr list
    แสดงปุ่มรับยศทั้งหมดในเซิร์ฟเวอร์

────────────────────────────────────────────────────────
  Register Panel                                  [ADMIN]
────────────────────────────────────────────────────────
/regpanel create <channel> [description]
    วางแผงปุ่มสมัครบัญชีในช่องทาง
    ประกอบด้วยปุ่ม 2 ปุ่ม (ทุกคนกดได้ / ephemeral):
      ⚔️ สมัครสมาชิก    — สมัครบัญชีเกมใหม่ (ผูก Discord อัตโนมัติ)
      🔑 เปลี่ยนรหัสผ่าน — เปลี่ยนรหัสผ่านบัญชีที่มีอยู่

/regpanel remove <message_id>
    ลบแผงปุ่มออกจากระบบและลบข้อความนั้น

/regpanel list
    แสดงแผงปุ่มทั้งหมดในเซิร์ฟเวอร์

────────────────────────────────────────────────────────
  Sticky Message                                  [ADMIN]
────────────────────────────────────────────────────────
/sticky set <channel> <message>
    ตั้งค่าข้อความติดหนึบในช่องทาง
    บอทจะลบข้อความเก่าและส่งใหม่ล่างสุดทุกครั้งที่มีข้อความเข้า

/sticky remove <channel>
    ลบข้อความติดหนึบออกจากช่องทาง

/sticky list
    แสดงช่องทางทั้งหมดที่ตั้งค่า Sticky Message ไว้

========================================================
  การตั้งค่า .env ที่สำคัญ
========================================================
DISCORD_TOKEN          — Token ของบอท (จาก Discord Developer Portal)
GUILD_ID               — Guild ID สำหรับ sync slash commands ทันที
REGISTER_CHANNEL_ID    — ห้องสมัครบัญชี (ใช้ใน Welcome embed ด้วย)
WELCOME_CHANNEL_ID     — ห้องส่งข้อความต้อนรับสมาชิกใหม่
STATUS_CHANNEL_ID      — ห้องแสดงสถานะเซิร์ฟเวอร์อัตโนมัติ
STATUS_POLL_INTERVAL   — ช่วงเวลาตรวจสอบ (วินาที ค่าเริ่มต้น 30)
DROP_CHANNEL_ID        — ห้องแจ้งเตือน Drop หายาก
ADMIN_ROLE_ID          — Role ID ที่มีสิทธิ์ใช้คำสั่ง [ADMIN]
VERIFIED_ROLE_ID       — Role ที่มอบให้หลัง verify สำเร็จ
RATHENA_HOST           — Host ของ rAthena (ค่าเริ่มต้น 127.0.0.1)
LOGIN_PORT             — Port login-server (ค่าเริ่มต้น 6900)
CHAR_PORT              — Port char-server  (ค่าเริ่มต้น 6121)
MAP_PORT               — Port map-server   (ค่าเริ่มต้น 5121)
WEB_PORT               — Port web-server   (ค่าเริ่มต้น 8888)

========================================================
  หมายเหตุ
========================================================
- คำสั่ง [ADMIN] ใช้ได้สำหรับ: เจ้าของเซิร์ฟเวอร์,
  สมาชิกที่มี Administrator permission, หรือสมาชิกที่มี
  ยศตรงกับ ADMIN_ROLE_ID ใน .env
- คำสั่งที่ต้องใช้ฐานข้อมูลจะไม่ทำงานหาก MySQL ไม่พร้อม
- ข้อมูล Reaction Role  บันทึกไว้ที่ data/reaction_roles.json
- ข้อมูล Register Panel บันทึกไว้ที่ data/register_panels.json
- ข้อมูล Sticky Message บันทึกไว้ที่ data/sticky_messages.json
- ข้อมูล Welcome Config  บันทึกไว้ที่ data/welcome.json
- ข้อมูล Status Message  บันทึกไว้ที่ data/status_message.json
