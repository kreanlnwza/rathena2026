- `/design-html` — สร้าง HTML production-quality

- `/ship` — workflow สำหรับ ship PR
- `/land-and-deploy` — merge และ deploy
- `/canary` — monitoring หลัง deploy
- `/benchmark` — ตรวจจับ performance regression
